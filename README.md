Customer Retention & Churn Analysis

Project Overview

This project analyzes customer churn data to identify patterns that lead to customer loss and provide recommendations to improve customer retention.

Objectives

- Analyze customer churn behavior
- Identify factors affecting customer retention
- Generate actionable business insights

Tools Used

- Microsoft Excel
- CSV Dataset
- GitHub

Key Insights

- Customers with lower tenure showed higher churn rates.
- Long-term customers were less likely to churn.
- Customer engagement plays a major role in retention.

Recommendations

- Improve customer support services.
- Introduce loyalty and reward programs.
- Provide personalized offers to at-risk customers.

Files Included

- customer_churn.csv
- churn_analysis.xlsx
- Churn_Analysis_Report.pdf
